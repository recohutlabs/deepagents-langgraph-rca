# Remote and Hybrid Work Security Policy

**Company:** Recohut Pvt Ltd
**Effective:** 2025-12-08

## Approved Tools and Networks

- Company data must not be stored in unauthorized tools such as personal Dropbox accounts.
- Home Wi-Fi must use WPA2 or WPA3 and must not retain the router's default password.
- Access to production servers and databases must always use the company VPN.

## Devices and Incidents

- Work devices must not be left unlocked in public spaces.
- A lost or stolen work device must be reported to IT within 2 hours.
- Suspicious email should be forwarded to the Security Team immediately.
